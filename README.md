# Pure Ink - Práctica 2

Práctica 02 de DWA (2026-27): web responsive e interactiva para Pure Ink, un estudio de tatuaje ficticio en Malasaña, Madrid.

- **Autora:** Victoria Eng de la Plaza
- **Repositorio:**
- **Web publicada (GitHub Pages):** 

## Obligaciones de Implementación
- HTML5 semántico
- CSS3 con variables, Flexbox y Grid. Es mobile-first, con 3 breakpoints: 768 px, 1024 px y 1280 px.
- jQuery 3.7.1 (CDN): menú responsive, slider automático, pestañas, filtro de galería, modal, carga al hacer scroll y validación del formulario.
- AOS 2.3.4 (CDN): aparición de bloques al hacer scroll.
- Typed.js 2.1.0 (CDN): texto que se escribe solo en el hero.

## Estructura

```
pure-ink/
├── index.html        Inicio
├── artistas.html     Artistas
├── galeria.html      Galería + modal
```

## Ramas

| Rama | Contenido |
|---|---|
| `main` | Versión estable. Solo recibe merges de las demás ramas. |
| `header-menu` | Cabecera fija y menú hamburguesa |
| `footer` | Pie de página con contacto |
| `inicio-hero` | Vídeo de fondo, Typed.js y fadeIn escalonado |
| `inicio-estudio` | Bloque «Diseños hechos para ti» |
| `inicio-galeria` | Filtros, hover y carga al hacer scroll |
| `slider` | Piezas recientes (slider automático) |
| `inicio-equipo` | Equipo y llamada a la acción |
| `artistas` | Página de artistas con pestañas |
| `galeria` | Página de galería y modal |
| `cita` | Formulario, preguntas frecuentes y mapa |
